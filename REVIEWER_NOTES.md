# Settle This — App Review Notes

This doc is for Apple / Google reviewers and any internal eng QA. Drop the
relevant sections into App Store Connect / Play Console at submission time.

## What the app does

Settle This is a private entertainment app that uses AI to generate
lighthearted opinions about low-stakes everyday disagreements such as chores,
laundry, leftovers, and roommate disputes. The app does **not** provide
therapy, legal advice, medical advice, financial advice, or crisis support.

## Posture

- **18+ launch.** A date-of-birth age gate runs before any AI feature is
  reachable. Under-18 users are blocked.
- **Disclaimer acceptance.** A versioned disclaimer must be accepted before
  reaching home.
- **No public feed.** No profiles, no follower graph, no comments, no DMs.
- **No NSFW mode.** PG default with PG-13 toggle reserved for a later release.
- **Private by default.** Saving a case is opt-in; users can soft-delete a
  case or hard-delete their account at any time from Settings → Delete data.

## Safety pipeline

Every AI generation runs through a two-stage server-side pipeline:

1. **Hosted moderation + bespoke safety classifier.** Flagged content is
   blocked with a brief safe explanation and no verdict is generated.
2. **Verdict generator** with a curated PG system prompt and explicit lists
   of disallowed humor targets (mental health, trauma, protected classes,
   etc.).

If the classifier fails for any reason (network, parse error, schema
mismatch), the pipeline **fails closed** to a calm soft-redirect template
rather than ever shipping a humor response.

Soft-redirect categories include possible emotional abuse, legal disputes,
medical questions, mental-health distress, and self-harm. These return a
calm, non-funny response with a recommendation to seek qualified support.

## User-generated content

Share cards leave the app only when the user actively taps the share sheet.
There is no in-app distribution. Each share card is gated by:

- `safety.safeForShare` (server-confirmed),
- absence of detected PII,
- `safety.riskLevel == 'low'`,
- successful verdict generation.

Cards include a "Generated by Settle This" footer and an "AI-generated
verdict" label.

## PII handling

The submit screen warns the user against sending names, phone numbers,
addresses, workplaces, or social handles. The backend runs a regex check; if
PII is detected and the user opts to save the case, PII is redacted before
sending to the model and the share card is suppressed.

## Account deletion

`Settings → Delete data → Delete my account` invokes a `deleteAccount` Cloud
Function that:

1. Soft-deletes (then hard-deletes) every case under `users/{uid}/cases`.
2. Empties `users/{uid}/usage`.
3. Anonymizes `feedback/*.userId` and `moderationLogs/*.userId`.
4. Deletes the `users/{uid}` profile document.
5. Calls `admin.auth().deleteUser(uid)`.

This satisfies Apple Guideline 5.1.1(v) and GDPR Article 17 / CCPA.
